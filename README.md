# Reroll Linux Documentation

Documentation site for Reroll Linux, a proposed minimal rolling-release Linux distribution
where critical system updates are recoverable by default.

Built with Vite + React + TypeScript.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
